## Scheduling Visualizer

## Project Description

The Scheduling Visualizer is a web application designed to help users visualize scheduling algorithms in action. Users can input data and observe how various algorithms manage scheduling tasks in real-time, enhancing their understanding of these algorithms.

## Features

- Interactive visualization of scheduling algorithms
- Ability to input custom task data
- Real-time updates as algorithms process tasks
- Support for multiple scheduling algorithms (e.g., FCFS, SJF, Round Robin)
- User-friendly interface with clear annotations

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: MongoDB
- Visualization Library: GSAP
